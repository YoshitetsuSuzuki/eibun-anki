# 英文暗記 — Recite

**<https://yoshitetsusuzuki.github.io/eibun-anki/>**

自作の英文を貼り付けるだけでカード化し、日本語訳を見て英文を思い出す練習ができる暗記帳です。
「覚えた / 苦手 / 未学習」に振り分けられ、苦手だけを集めてランダムにテストできます。

- URL を開くだけで誰でも使えます。登録もログインも不要です。
- データは各自の端末内（`localStorage`）にのみ保存されます。他の人のデータと混ざることはありません。
- PWA 対応。ホーム画面に追加すればアプリのように起動し、オフラインでも動きます。

## 使い方

### 1. 英文を取り込む

ホームの「英文を取り込む」を開き、作った英文と日本語訳を貼り付けます。
形式は問いません。次のどれでも読み取ります。

```
- I have been thinking about it all week.
- そのことを一週間ずっと考えていました。

Let me get back to you tomorrow. | 明日、折り返しご連絡します。

Could you give me a hand?	手を貸していただけますか。

すべてあなた次第です。
It's completely up to you.
```

- 英語と日本語の順番は問いません（どちらが先でも判定します）
- 行頭の `-` `・` `1.` `①` などは自動で外します
- 区切りは タブ / `|` / `｜` / `=` / `：` / `→` / `／` / 全角スペースに対応
- 区切りがなくても、英語と日本語の切り替わる位置で分けます
- 相方が見つからなかった行は「要修正」として残り、プレビュー上でその場で直せます
- 同じ英文の重複は自動で検出し、既定では取り込みません

### 2. 暗記カードで覚える

デッキを開くと、取り込んだ英文がカードとして並びます。既定では **日本語が表** です。

- **カードをタップ** すると裏返って英文が出ます
- **「全部ひっくり返す」** で、並んでいるカードを一斉に裏返せます（英語面 ⇄ 日本語面）
- **「並べ替え」** でカードの順番をランダムに入れ替えます
- 答えの面に「まだ / 苦手 / 覚えた」が出るので、思い出せたかどうかをその場で記録できます
- 左下の点が現在の状態（緑＝覚えた / 橙＝苦手 / 灰＝まだ）を示します

### 3. 英文・和訳の一覧を見る

同じ画面のタブを「英文・和訳の一覧」に切り替えると、英文と訳が最初から両方見える一覧になります。
読み返し・確認用です。ここではカードの修正と削除もできます。

### 4. テストする

「この N 枚をテスト」で、1 枚ずつの本番形式に入ります。日本語が出て、めくると英文。
絞り込み（すべて / 苦手 / まだ / 覚えた）がそのままテストの範囲になります。

キーボード操作:

| キー | 動作 |
| --- | --- |
| `Space` / `Enter` | めくる（めくった後は「覚えた」） |
| `1` / `2` / `3` | まだ / 苦手 / 覚えた |
| `Esc` | 学習をやめる |

右上のアイコンで、出題方向（日本語 → 英文 ⇄ 英文 → 日本語）を切り替えられます。

### 5. 苦手だけテストする

ホームの「苦手テスト」で、全デッキの苦手カードだけをランダムに出題します。
デッキごとの「苦手 N」からは、そのデッキの苦手だけを出題できます。

### バックアップ

設定の「書き出す」で全データを JSON ファイルに保存できます。
「読み込む」では、今のデータに追加するか置き換えるかを選べます。

## 開発

```bash
npm install
npm run dev
```

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー |
| `npm run test` | Vitest（98 件） |
| `npm run typecheck` | 型検査 |
| `npm run build` | 型検査 + 本番ビルド（`dist/`） |
| `npm run preview` | ビルド結果の確認 |
| `npm run icons` | アイコン PNG の再生成 |

### 構成

```
src/
  lib/parser.ts    貼り付けテキスト → カード（+ テスト）
  lib/storage.ts   localStorage への読み書きと検証（+ テスト）
  lib/actions.ts   状態遷移（純粋関数、+ テスト）
  lib/study.ts     出題対象の抽出とシャッフル（+ テスト）
  lib/board.ts     カード盤面の並び順と表裏（+ テスト）
  lib/speech.ts    端末内蔵の音声合成
  lib/backup.ts    JSON の書き出し / 読み込み
  components/      Home / ImportView / DeckView / StudyView
  styles/          トークン（base.css）と部品（app.css）
```

ロジックはすべて純粋関数として `src/lib` に置き、DOM を使わずにテストしています。

## 公開

`main` に push すると、GitHub Actions（`.github/workflows/deploy.yml`）がテストとビルドを
通したうえで GitHub Pages へ自動デプロイします。

- 公開 URL: <https://yoshitetsusuzuki.github.io/eibun-anki/>
- `vite.config.ts` の `base` は `'./'` のため、サブパス配信でもそのまま動きます
- サーバーもデータベースも使っていないため、運用費はかかりません

### アプリとしてホーム画面に追加する

| 端末 | 手順 |
| --- | --- |
| iPhone / iPad | **Safari** で開く → 共有ボタン（□に↑）→ 「ホーム画面に追加」 |
| Android | Chrome で開く → 右上 ⋮ → 「アプリをインストール」 |
| Mac | Safari: 「ファイル」→「Dock に追加」／Chrome: アドレスバー右のインストールアイコン |
| Windows | Chrome・Edge: アドレスバー右のインストールアイコン |

iPhone は Safari 以外のブラウザからは追加できません。追加後はアドレスバーのない全画面で起動し、
オフラインでも動きます。

**注意**: iOS ではブラウザで見ていたデータと、ホーム画面アプリのデータが別々に扱われることがあります。
先にホーム画面へ追加してから英文を取り込むのが安全です。すでにブラウザ側にカードがある場合は、
設定の「書き出す」で JSON を保存し、ホーム画面アプリ側で「読み込む」と移せます。

### データの扱い

保存先は各利用者のブラウザの `localStorage` だけです。サーバーへ送信される情報はありません。
そのため利用者どうしのデータは完全に独立していますが、同じデータを複数の端末で共有することも
できません。端末をまたぎたい場合は、設定の「書き出す」「読み込む」で JSON を移してください。
