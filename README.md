# 英文暗記 — Recite

自作の英文を貼り付けるだけでカード化し、日本語訳を見て英文を思い出す練習ができる暗記帳です。
「覚えた / 苦手 / 未学習」に振り分けられ、苦手だけを集めてランダムにテストできます。

- データは端末内（`localStorage`）にのみ保存されます。アカウントも通信も不要です。
- PWA 対応。ホーム画面に追加すればアプリのように起動し、オフラインでも動きます。

## 使い方

### 1. 英文を取り込む

ホームの「英文を取り込む」を開き、作った英文と日本語訳を貼り付けます。
形式は問いません。次のどれでも読み取ります。

```
- I have been thinking about it all week.
- そのことを一週間ずっと考えていました。

Let me get back to you tomorrow. | 明日、折り返しご連絡します。

Could you give me a hand?	手を貸していただけますか。

すべてあなた次第です。
It's completely up to you.
```

- 英語と日本語の順番は問いません（どちらが先でも判定します）
- 行頭の `-` `・` `1.` `①` などは自動で外します
- 区切りは タブ / `|` / `｜` / `=` / `：` / `→` / `／` / 全角スペースに対応
- 区切りがなくても、英語と日本語の切り替わる位置で分けます
- 相方が見つからなかった行は「要修正」として残り、プレビュー上でその場で直せます
- 同じ英文の重複は自動で検出し、既定では取り込みません

### 2. 学習する

カードをタップすると裏返って英文が出ます。裏面で「まだ / 苦手 / 覚えた」を選ぶと
次のカードへ進みます。

キーボード操作:

| キー | 動作 |
| --- | --- |
| `Space` / `Enter` | めくる（めくった後は「覚えた」） |
| `1` / `2` / `3` | まだ / 苦手 / 覚えた |
| `Esc` | 学習をやめる |

右上のアイコンで、出題方向（日本語 → 英文 ⇄ 英文 → 日本語）を切り替えられます。

### 3. 苦手だけテストする

ホームの「苦手テスト」で、全デッキの苦手カードだけをランダムに出題します。
デッキごとの「苦手 N」からは、そのデッキの苦手だけを出題できます。

### バックアップ

設定の「書き出す」で全データを JSON ファイルに保存できます。
「読み込む」では、今のデータに追加するか置き換えるかを選べます。

## 開発

```bash
npm install
npm run dev
```

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー |
| `npm run test` | Vitest（88 件） |
| `npm run typecheck` | 型検査 |
| `npm run build` | 型検査 + 本番ビルド（`dist/`） |
| `npm run preview` | ビルド結果の確認 |
| `npm run icons` | アイコン PNG の再生成 |

### 構成

```
src/
  lib/parser.ts    貼り付けテキスト → カード（+ テスト）
  lib/storage.ts   localStorage への読み書きと検証（+ テスト）
  lib/actions.ts   状態遷移（純粋関数、+ テスト）
  lib/study.ts     出題対象の抽出とシャッフル（+ テスト）
  lib/speech.ts    端末内蔵の音声合成
  lib/backup.ts    JSON の書き出し / 読み込み
  components/      Home / ImportView / DeckView / StudyView
  styles/          トークン（base.css）と部品（app.css）
```

ロジックはすべて純粋関数として `src/lib` に置き、DOM を使わずにテストしています。

## 公開する場合

`npm run build` で出力される `dist/` をそのまま静的ホスティングに置けます。
`vite.config.ts` の `base` は `'./'` なので、サブパス配信（GitHub Pages の
`https://<user>.github.io/<repo>/` 形式）でもそのまま動きます。

iPhone では Safari で開き、共有メニューから「ホーム画面に追加」でアプリとして使えます。
