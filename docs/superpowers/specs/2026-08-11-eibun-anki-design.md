# 英文暗記アプリ 設計書

作成日: 2026-08-11

## 目的

自作した英文を貼り付けるだけでカード化し、日本語訳 → 英文の想起練習を行う単語帳アプリ。
「覚えた / 苦手 / 未学習」に振り分け、苦手だけを集めてランダムにテストできることを中心機能とする。

## 動作環境

- Web アプリ（PWA）。ブラウザで動作し、ホーム画面に追加すればアプリのように使える。
- データは端末内 `localStorage` のみ。サーバー・アカウント・通信は一切なし。
- Vite + React 19 + TypeScript。スタイルは素の CSS（CSS 変数によるテーマ制御）。
- テストは Vitest（純粋関数のみを対象、DOM 不要）。

## 画面構成

| 画面 | 役割 |
| --- | --- |
| ホーム | 全体の集計（覚えた/苦手/未学習）、デッキ一覧、各デッキの進捗と操作 |
| 取り込み | テキスト貼付 → 自動パース → プレビューで修正 → デッキとして保存 |
| 学習 | カード1枚ずつ。タップで反転。裏面で「まだ / 苦手 / 覚えた」を選択 |
| 結果 | セッション終了時のサマリと再挑戦導線 |

「苦手テスト」は学習画面の起動オプション（対象 = 全デッキの苦手カード、順序 = ランダム）として実装し、
画面を増やさない。

## データモデル

```ts
type Status = 'new' | 'weak' | 'known'

type Deck = { id: string; name: string; createdAt: number }

type Card = {
  id: string
  deckId: string
  en: string
  ja: string
  status: Status
  reviewCount: number
  lastReviewedAt: number | null
}

type Settings = { theme: 'dark' | 'light'; speakOnReveal: boolean }

type AppState = { version: 1; decks: Deck[]; cards: Card[]; settings: Settings }
```

永続化キー: `eibun-anki:v1`。読み込み時は形の検証を行い、壊れていれば初期状態に戻す
（アプリが起動不能になることを防ぐ）。

## 取り込みパーサー仕様

入力テキストを行単位で処理する。

1. 各行の行頭装飾（`- `, `* `, `・`, `1. `, `1)`, `①`〜`⑳`, `■`, `●`）と前後空白を除去する。
2. 行内に区切り文字（タブ, `|`, `｜`, ` / `, `=`, `：`, `:`, `::`, `→`, `\t`）があり、
   分割した左右の一方に日本語文字が含まれ他方に含まれない場合、その1行を1カードとする。
3. 区切りがない場合は連続する2行を1組として扱う。日本語文字の有無で英文・訳文を判定するため、
   英語が先でも日本語が先でも良い。
4. 空行はカードの区切りとして扱う（3行以上連続するブロックは 2 行ずつ組にする）。
5. 相方が見つからない行は破棄せず「要修正」として結果に含め、プレビュー上で編集・削除できる。
6. 同一入力内および保存先デッキ内で英文が重複するカードは「重複」として印を付ける（既定で取り込まない）。

判定用の日本語検出は、ひらがな・カタカナ・漢字・全角記号の Unicode 範囲で行う。

## 学習ロジック

- セッション開始時に対象カードを抽出し、Fisher–Yates でシャッフルする。
- 出題方向は `ja→en`（既定）と `en→ja` をトグルで切り替え。
- 表面をタップ/クリック/Space で反転。裏面で 3 択:
  - 「まだ」→ `new`
  - 「苦手」→ `weak`
  - 「覚えた」→ `known`
- いずれの選択でも `reviewCount` を +1、`lastReviewedAt` を更新して次のカードへ。
- セッション末に結果サマリを表示し、「苦手だけもう一度」「同じ条件でもう一度」「ホームへ」を提示。

## 追加機能

- **音声読み上げ**: Web Speech API（`speechSynthesis`）。英文表示時に自動再生する設定と、
  手動再生ボタン。API 未対応環境ではボタンを出さない。
- **JSON バックアップ**: 全状態のエクスポート（ダウンロード）とインポート（置換 / 追加を選択）。
- **集計表示**: ホームで全体とデッキ別の内訳を帯グラフと数値で表示。

## デザイン方針

夜の書斎をイメージした「インクと灯り」。既定はダークテーマ。

- 背景は純黒を避けた深い炭色、文字は純白を避けた `#E7E4DC` 系。眼精疲労を抑える。
- アクセント: 琥珀 = 苦手 / 灯り、セージ = 覚えた、鈍色 = 未学習。
- 英文は Newsreader（セリフ体）、日本語は Zen Kaku Gothic New。Web フォントが読めない環境では
  端末のセリフ/ゴシックにフォールバックする。
- カードは 3D フリップ（`transform: rotateY`）。`prefers-reduced-motion` を尊重する。
- ライト（和紙）テーマも用意し、ヘッダーで切替。

## 非対象（YAGNI）

間隔反復（SRS）のスケジューリング、クラウド同期、アカウント、タイピング入力採点、画像・音声ファイルの添付。
